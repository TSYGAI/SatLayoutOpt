# SatLayoutOpt

SatLayoutOpt 是一个面向卫星舱段配载方案探索的三维工作台。项目以 STEP 模型为几何源，串联模型管理、安装约束设置、舱段参数配置和布局优化，让配载方案能够在浏览器中预览、比较和导出。

## 项目简介

卫星配载需要同时考虑模型外形、安装方向、舱段空间、相互避让以及整体质量分布。SatLayoutOpt 将这些输入组织成一套连续流程：导入卫星模型，设置安装信息和安全包络，确定舱段尺寸范围与装载数量，再由后端搜索满足约束的候选布局。原始 STEP 文件保留为精确几何源；浏览器预览使用按需生成的三角网格。

## 主要功能

| 功能 | 内容 |
| --- | --- |
| 模型上传 | 导入 `.stp` / `.step` 模型，查看三维预览和模型几何信息。 |
| 卫星设置 | 配置单位、比例、质量、质心、安装面与朝上方向，生成安全包络并固化模型记录。 |
| 前置配置 | 设置卫星装载数量、舱段半径和高度范围、中轴半径及整流罩半径。 |
| 布局优化 | 根据几何、安装、碰撞和质量约束搜索候选方案，预览布局、查看历史项目并导出 Excel 安装参数。 |
| 数据管理 | 检索、查看和删除已固化的模型记录。 |

典型流程：**上传 STEP 模型 → 完成卫星设置与包络生成 → 固化模型 → 配置装载条件 → 运行布局优化 → 比较、保存与导出方案**。

## 技术组成

- 前端：React、Vite、Three.js，负责页面交互和三维预览。
- 后端：FastAPI、CadQuery / OpenCascade，负责接口、STEP 几何处理和布局计算。
- 数据：SQLite 保存模型元数据，项目本地目录保存原始模型、派生产物及历史结果。

## 本地运行

准备 Python 3.12、Node.js 和 npm，并在已激活的 Python 环境中于项目根目录执行：

```powershell
python -m pip install -r backend/requirements.txt
npm --prefix frontend ci
```

Windows 下从该环境运行 `start-dev.bat`；也可以设置 `SAT_LAYOUT_OPT_PYTHON` 指向要使用的 Python 可执行文件。启动后访问 `http://127.0.0.1:11111/frontend/model-upload`。

## 当前边界

布局优化采用启发式搜索，候选结果会按项目中的几何和质量约束验收，但不保证全局最优。当前整流罩空间按圆柱段处理，尚未纳入锥头、实际支座结构及其质量；结果适合方案探索和比较，不能代替最终工程校核。
